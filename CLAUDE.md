## What this repo is

This is a portfolio index repository — it contains only a `README.md` that links to Alexandre's other GitHub projects. There is no runnable code here.

## Updating the README

When adding a new project, follow the existing pattern:
- Add a `##` section header with a project number or category
- Link the repo name with `[**Repo Name**](url)`
- List the key technologies as a bullet list under `#### Repo Overview:`
- Add a `skillicons.dev` badge line for the tech stack

Skill icon IDs: https://skillicons.dev — the `i=` parameter takes comma-separated IDs (e.g. `terraform,kubernetes,docker`).

The README uses a flat single-file structure with no includes or templating.
